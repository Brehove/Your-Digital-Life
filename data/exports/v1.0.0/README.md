# Your Digital Life data v1.0.0

Replaces the hourly coding-agent row with a qualified intensive per-request example and updates its evidence, water scenario, and starter preset.

The live coding activity changes from an unsupported hourly normalization to an intensive per-human-request modeled example. Energy is 150 Wh per request; direct and broader water are inferred project scenarios of 150 mL and 900 mL. The reference is not a generic user average or direct provider measurement.

The website consumes a generated snapshot from these root records, and `latest/` is byte-identical to this versioned package. Historical release directories and archives remain immutable. The frozen object captured from Git commit `063322e93e27704b447a495a838e552067928127` remains provenance metadata and a repository-only regression fixture; it is not an update authority.

## Changes

- Replaced the live vibe-coding hourly row with coding-agent-requests-intensive, an explicitly qualified per-human-request activity.
- Adopted 150 Wh per request from 170,000 Wh divided by 1,138 typed human prompts in Hausfather's modeled intensive Claude Code workload; automatic model and subagent calls represented in the logs remain inside that denominator.
- Applied the existing inferred AI water scenario to the new row: 150 mL direct and 900 mL broader water per request, with broader water including direct water.
- Removed the historical 30 Wh laptop increment and coding-device preset selection; omitted device, network, external tool execution, training, and embodied energy remain unquantified.
- Changed the Gen Z vibe-coder starter from one coding-agent hour to 15 illustrative agentic tasks, counted as 15 human coding-agent requests without claiming verified completed outcomes, while preserving all other quantities and device selections.
- Added optional activity displayQualifier and shortLabel fields, the requests unit, the operational-coding-request boundary, and an optional display_qualifier CSV column.
- Preserved Couch as historical provenance and credited Ippolito separately for the discovery trail and action/depth framework; neither supplies the adopted 150 Wh coefficient.
- Preserved all immutable v0.1.0 through v0.4.1 exports and release history.
