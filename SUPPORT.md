# Support

This project uses GitHub as its support and contribution system:

- **Using or interpreting the data:** Q&A Discussion.
- **Methodology question:** Methodology Discussion.
- **New publication worth tracking:** New Research / Source Watch Discussion.
- **Questionable value:** Data correction Issue Form.
- **New activity or source:** New data or source Issue Form.
- **Website problem:** Website bug Issue Form.
- **Documentation problem:** Documentation Issue Form.
- **Security or private information:** follow `SECURITY.md`.

No separate support email is published or monitored. GitHub Discussions,
Issues, pull requests, and private security advisories are the supported
channels. Support is community-based and has no guaranteed response time.

Search existing records, Issues, and Discussions before opening a new thread.
Include stable record IDs, exact URLs, units, system boundaries, and source
locators when they apply.
