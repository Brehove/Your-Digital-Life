This page is the reference point for the most common public question: *"What does prompting ChatGPT actually use?"* It should keep the training-versus-inference split, the large spread across task types, and the honest Netflix-style comparisons together in one place.

The coding-agent comparison uses about 150 Wh per human request as an intensive-use example. Count each message a person sends, including follow-ups and failed requests; automatic agent steps and subagents do not add human requests. The estimate comes from 170 kWh modeled across 1,138 requests in one intensive Claude Code workload. It models the logged model activity, while external tool execution is not separately measured. It is not a duration, a completed-task unit, or a general average, and the exact model mix was not reported.

The corresponding 150 mL direct-water and 900 mL broader-water figures are inferred with the calculator's existing 1 mL/Wh and 6 mL/Wh teaching assumptions. They were not measured by the coding-energy source and do not describe a particular provider or location. Jon Ippolito's *What Uses More?* supplied the comparison framework and research trail; the adopted 150 Wh reference comes directly from the Hausfather analysis.
