## Choose a contribution path

- [Propose a data correction](https://github.com/Brehove/Your-Digital-Life/issues/new?template=data-correction.yml) for a questionable value, calculation, source, or boundary.
- [Propose a new activity or source](https://github.com/Brehove/Your-Digital-Life/issues/new?template=new-data-or-source.yml) when the record does not yet exist.
- [Open a general GitHub Issue](https://github.com/Brehove/Your-Digital-Life/issues) for a website defect or documentation problem.
- [Start a GitHub Discussion](https://github.com/Brehove/Your-Digital-Life/discussions) for an open-ended methodology question or proposal.
- Read [CONTRIBUTING.md](https://github.com/Brehove/Your-Digital-Life/blob/main/CONTRIBUTING.md) before preparing a pull request.

For a data correction or addition, identify the stable record ID, current and proposed values, unit, system boundary, source URL or DOI, exact source location, calculation with intermediate steps, confidence or status, and affected exports or public explanations. Prefer a primary source when one is available, and state material limitations.

## Evidence and rights

Do not submit confidential information, personal data, paywalled full text, publisher charts, logos, screenshots, or substantial quotations without documented permission. A citation supports a claim; it does not grant permission to copy the source's expression.

Contributions follow the license that governs their destination: MIT for code, CC0 1.0 for project-created data and schemas, and CC BY 4.0 for original project prose and methodology. By submitting a contribution, you affirm that you have the right to provide it under the applicable license.

Security or private-data reports should follow [SECURITY.md](https://github.com/Brehove/Your-Digital-Life/blob/main/SECURITY.md), not a public Issue.
