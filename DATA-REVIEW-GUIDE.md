# Your Digital Life data review guide

> [!IMPORTANT]
> This file is generated by `npm run data:build`. Do not edit it by hand. Edit the canonical records under `data/` or the reviewer metadata under `data/review/`, then regenerate it.

This is the human-readable review surface for calculator dataset **v0.4.0**, evidence overlays **v0.3.0**, reviewed **2026-07-14**. It combines the current canonical values with review-only evidence and external-comparison records.

The reviewer metadata is deliberately separate from the release data. It is not a calculator input, website input, or release artifact. A future data release may merge reviewed metadata only through the normal versioned release process.

## How to read the numbers

The calculator preserves legacy row-specific boundaries. These columns are useful for comparison, but they are not all measurements of one standardized end-to-end system.

| Field | Current definition |
| --- | --- |
| `serverWhPerUnit` | The deployed calculator's row-specific cloud/server or server-plus-network boundary; exact scope remains in each legacy note and method record. |
| `totalWhPerUnit` | The deployed calculator's row-specific total-system boundary, including configured device overrides where modeled. |
| `directWaterMlPerUnit` | The deployed calculator's direct-water metric for the row; activity-specific boundary text is included where available. |
| `totalWaterMlPerUnit` | The deployed calculator's broader total-water metric for the row; activity-specific boundary text is included where available. |

The strongest review question is therefore not only “is this number right?” It is also: **right for which workload, hardware, date, geography, and system boundary?**
